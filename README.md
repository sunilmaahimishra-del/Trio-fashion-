# Trio Fashion Ecommerce Structure

This starter contains:
- Product catalog
- LocalStorage cart
- Customer checkout form
- Success page
- Backend placeholder for secure Razorpay integration

## Important
The current GitHub Pages frontend does NOT process real payments yet.
Before going live, connect the checkout to a secure backend/serverless function and verify Razorpay payments server-side.

Never upload `.env` or the Razorpay Key Secret to GitHub.
